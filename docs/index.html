📖 Overview

🔢 What is Hisaab?

Hisaab (حساب) is a comprehensive JavaScript library for calculating Arabic name values using the traditional Abjad system. It combines mathematical precision with Islamic spiritual wisdom and Arabic astrological traditions.

🌟 Key Features

  • ✅ Accurate Abjad calculation (28+ Arabic letters)
  • ☪️ 99 Names of Allah analysis
  • 📖 Quranic verse connections
  • 🌙 28 Lunar Mansions (منازل القمر)
  • ⭐ Traditional Arabic astrology
  • 💕 حساب الشريك compatibility
  • 💼 Business name analysis (v1.3.0)
  • 📅 Date integration & life path (v1.3.0)
  • 🔮 Advanced numerology (v1.3.0)
  • 🕌 Prayer guidance & dhikr (v1.3.0)

🎯 Use Cases

  • 👶 Baby name selection

  • 🤲 Spiritual guidance
  • 📚 Educational tools
  • 🔮 Numerological analysis
  • 💼 Business name analysis

🚀 Quick Start

Basic Usage

// Import the library
const Hisaab = require('hisaab');

// Create an instance with an Arabic name
const name = new Hisaab('محمد');

// Get basic information
console.log(name.getName());    // 'محمد'
console.log(name.getValue());   // 92
console.log(name.getDigitRoot()); // 2

// Get letter breakdown
console.log(name.getBreakdown());
// [
//   { letter: 'م', value: 40 },
//   { letter: 'ح', value: 8 },
//   { letter: 'م', value: 40 },
//   { letter: 'د', value: 4 }
// ]

// Islamic analysis
const islamicAnalysis = name.getIslamicAnalysis();
console.log(islamicAnalysis.islamicQualities);

// Arabic astrology
const astrology = name.getArabicAstrology();
console.log(astrology.element.arabic); // 'الماء' (Water)

Compatibility Check

// Arabic compatibility (حساب الشريك)
const compatibility = Hisaab.compareArabic('محمد', 'فاطمة');

console.log(compatibility.partnerHouse); // 9
console.log(compatibility.interpretation.quality); // 'Very Bad'
console.log(compatibility.calculation); // '2 + 9 + 7 = 18 → 9'

// Complete comparison (both systems)
const fullComparison = Hisaab.compare('علي', 'خديجة');
console.log(fullComparison.arabic.partnerHouse); // Arabic result
console.log(fullComparison.western.compatibilityScore); // Western result

🔤 Abjad Calculation System

The Abjad system assigns numerical values to Arabic letters according to their traditional order:

Letter Name Value Letter Name Value Letter Name Value
اAlif1 كKaf20 رRa200
بBa2 لLam30 شShin300
جJim3 مMim40 تTa400
دDal4 نNun50 ثTha500
هHa5 سSin60 خKha600
وWaw6 عAin70 ذDhal700
زZay7 فFa80 ضDad800
حHa8 صSad90 ظZha900
طTa9 قQaf100 غGhayn1000
يYa10 Special: ة (Ta Marbuta) = 5

🧮 Calculation Example: فاطمة

ف = 80
ا = 1
ط = 9
م = 40
ة = 5
Total: 80 + 1 + 9 + 40 + 5 = 135

💕 حساب الشريك (Arabic Partner Calculation)

Traditional Arabic method for calculating relationship compatibility using the formula:

Partner House = (DigitRoot1 + DigitRoot2 + 7) → Final Digit Root
The number 7 represents the house of relation between two people
House Arabic Quality Rating Description
1 سيء Bad 6/10 Starts well but faces challenges later
2 جيد Good 6/10 Wealth with complications, woman faces family issues
3 سيء جداً Very Bad 7/10 Family conflicts, wealth after loss
4 جيد جداً Very Good 7/10 Clean wealth, possible divorce in 5 years
5 محايد Neutral 5/10 Good for politicians/famous, many children
6 سيء جداً Very Bad 9/10 Misfortune but peaceful coexistence
7 ممتاز Perfect 10/10 🌟 Most wanted house - perfect harmony!
8 محايد Neutral 5/10 Excellent for scholars/royals, bad for business
9 سيء جداً Very Bad 10/10 ❌ Worst case - avoid this combination!

Example Calculation

// محمد (92) → Digit Root: 2
// فاطمة (135) → Digit Root: 9
// Calculation: 2 + 9 + 7 = 18 → 1 + 8 = 9 (Very Bad)

const compatibility = Hisaab.compareArabic('محمد', 'فاطمة');
console.log(compatibility.partnerHouse);           // 9
console.log(compatibility.interpretation.quality); // 'Very Bad'
console.log(compatibility.calculation);            // '2 + 9 + 7 = 18 → 9'

🔧 API Reference

Constructor

new Hisaab(arabicName: string)

Creates a new Hisaab instance for the given Arabic name.

Parameters:

  • arabicName (string): The Arabic name to analyze

Example:

const hisaab = new Hisaab('محمد');

Basic Methods

getValue(): number

Returns the calculated Abjad value of the name.

hisaab.getValue(); // 92

getDigitRoot(): number

Returns the digit root (repeated sum until single digit).

hisaab.getDigitRoot(); // 2

getBreakdown(): Array<{letter: string, value: number}>

Returns detailed breakdown of each letter and its value.

hisaab.getBreakdown();
// [{ letter: 'م', value: 40 }, { letter: 'ح', value: 8 }, ...]

    ['يوسف', 'مريم']
];

couples.forEach(([name1, name2]) => {
    const comp = Hisaab.compareArabic(name1, name2);

});
